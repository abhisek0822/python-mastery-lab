# Mini Shell

A simple Linux-like shell implemented in Python.

## Features

- pwd
- ls
- cd
- mkdir
- touch
- cat
- clear
- help
- exit

## Run

```bash
python main.py
```

## Example

```text
mini-shell> pwd

mini-shell> ls

mini-shell> mkdir demo

mini-shell> cd demo

mini-shell> touch hello.txt

mini-shell> cat hello.txt

mini-shell> exit
```
